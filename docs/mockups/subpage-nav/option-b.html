Option B, refined: a branch switcher that opens a site map

The branch tabs fold into "InsideGov / Presidency ▾" by the wordmark, and the rest of the row goes to that branch's pages, all seven at once. Three rules make up for the tabs going behind a menu:

  1. The switcher opens a map of the whole site: every branch with all its pages, so one click shows everything and goes straight to any page (Congress › Wealth from a Presidency page).
  2. The switcher only appears inside a branch (its pages and its profile pages). The homepage, Timeline, About and Methodology keep today's branch tabs, so there's never a switcher with an empty row beside it.
  3. Spacing tightens below ~1100px so all seven still fit at 1024px; narrower than that, the existing "+N ›" button takes over.

Try it

Click the switcher, pick any page, or click the wordmark (home) or Timeline in the map to see the header go back to the branch tabs. Esc or a click outside closes the map.
